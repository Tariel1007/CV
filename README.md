# Personal Portfolio Website

A modern, responsive portfolio website built with React, showcasing my work and skills.

## Features

- Responsive design
- Modern UI/UX
- Smooth animations
- Project showcase
- Skills section
- Contact form
- Dark/Light mode

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Technologies Used

- React
- Styled Components
- Framer Motion
- React Icons
- HTML5
- CSS3
- JavaScript
